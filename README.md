# Sakina Legal Pages

Static legal and compliance pages for the [Sakina](https://example.com) app — a spiritual wellness and mood tracking application.

## Pages

| File | Purpose |
|------|---------|
| `privacy.html` | Privacy Policy — data collection, third-party services, user rights (CCPA/GDPR) |
| `terms.html` | Terms of Service |
| `deletion.html` | Account deletion instructions |
| `delete-account.html` | In-app account deletion flow |

## About Sakina

Sakina is a mood and spiritual wellness app that tracks mood entries, reflections, prayer times (via location), and journal history. Data is stored locally on-device with optional cloud sync via Supabase.

## Deployment

These pages are static HTML files. Host them on any static site host (GitHub Pages, Netlify, Vercel, etc.) or embed them as WebView screens in the Android app.
